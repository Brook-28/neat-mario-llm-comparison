# neat-mario-llm-comparison
Lietuviškai: Metinio projekto tyrimas: kaip skiriasi žmogaus ir trijų LLM (ChatGPT, Gemini, Claude) sukurti NEAT sprendimai mokant DI agentą pereiti pirmąjį „Super Mario Bros" lygį. 
English: A school research project comparing human vs. LLM-generated (ChatGPT, Gemini, Claude) NEAT solutions for training an AI agent to beat the first level of Super Mario Bros.
